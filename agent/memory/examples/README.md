# 可核对的 SQLite 记忆实验

运行 `python3 agent/memory/examples/lexical_memory.py`，需要 Python 自带 SQLite 启用了 FTS5。只使用标准库，不联网、不调用模型、不读真实会话、不落盘数据库。

实验显式写入三条事实，以 `supersedes` 更新旧事实的生效区间，用 FTS5 的 BM25 排序，并用 tenant/project/as_of 过滤。断言旧时间得到pip，新时间得到uv，不返回另一个用户或项目的记录，无匹配时为空，逻辑撤销后不再检出。

这里的决策者就是 Python 主程序：它已经知道哪条事实应被更新，没有“另一个LLM”或自动语义冲突检测。查询使用英文索引关键词，不把 unicode61 当作中文分词器。若语义不同而无共享词项，实验会漏召回；这正是加入dense检索前应测量的词法基线。

`revoked=1` 是逻辑撤销，不会清除原始日志、FTS或备份。不能用这个实验宣称已满足隐私物理删除；生产方案须删除所有派生索引和事件来源，防止重新提取恢复它。

本例没有持久化、Embedding、RRF、图、后台提取、租户级物理隔离或端到端LLM问答。通用设计和完整评测方案见上级章节。
