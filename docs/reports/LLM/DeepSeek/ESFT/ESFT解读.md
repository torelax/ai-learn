# ESFT：补充解读

> 只更新专家和只让模型使用这些专家，是同一件事吗？以下为直觉解释与应用延伸，论文内容见 [精炼主笔记](ESFT详解.md)。

## 这里的“专家”不必对应人类学科

路由偏好可以反映格式、语言、位置、语法与内容的混合。某些专家在法律任务中活跃，不等于它们只保存法律知识。ESFT 依靠统计相关性选择更新对象，并不需要先证明每个专家都有一个清晰标签。

## 和 LoRA 应如何比较

ESFT 更新的是部分原权重，LoRA 给很多模块添加低秩变化；一个利用结构稀疏，一个利用增量低秩。比较时应对齐实际可训练参数、优化器显存、训练墙钟时间、增量保存大小与通用能力，而不是只比较名称。

## 小样本路由统计什么时候会失效

选择集若缺少长输入、罕见语言或重要子任务，可能漏掉实际需要的专家。可以把任务分层抽样，并检查不同抽样种子的专家集合与验证集效果；不要把 32 条当作固定配方。

## 用一个具体场景串起来

不是。ESFT冻结大部分专家，但前向路由仍可访问它们；冻结参数不需要权重梯度，却不等于中间表示完全不参与反向，也不等于推理时删除了它们。完整模型仍需加载或分布式管理。

如果任务数据包含两类差异很大的工作流，32条样本只覆盖其中一类，选出的专家可能漏掉另一类。相关性统计稳定是分布内观察；面对混合或迁移任务，评分样本的覆盖比机械复制阈值更重要。
