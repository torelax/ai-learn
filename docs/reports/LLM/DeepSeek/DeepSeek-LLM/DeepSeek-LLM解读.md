# DeepSeek-LLM 补充解读

> 如何把 scaling law 读成实验设计，而非万能配方？以下为直觉解释与应用延伸，论文内容见 [精炼主笔记](DeepSeek-LLM详解.md)。

## 为什么不要直接背拟合系数

把 scaling law 当成实验组织方法，比背下学习率公式更有价值。需要先明确验证集、数据混合、tokenizer 与 FLOPs 口径，再在几个预算上寻找近优区域。若数据质量变化，旧曲线可能失效；本文早期与新数据的指数差异已经给出例子。

## 从 Python 训练者的角度看成本

一次大训练之前的小实验，应同时记录有效 token 数、吞吐、loss 与目标任务分数。相同 step 数不等于相同计算预算；padding、序列长度和词表计算都会改变成本。报告用每 token 非 embedding FLOPs 替代简单参数计数，提醒我们先统一度量再谈规律。

## 对齐不能只看平均分

报告观察到数学 SFT 数据增加可能伴随循环重复，而 DPO 的收益更多出现在开放式生成。为此，评测里除了知识和数学准确率，也需要终止率、重复率与真实交互质量。一个平均 benchmark 分数无法代表可用性。


## 用一个具体场景串起来

假设只能追加一笔训练预算：扩大参数会增加每步成本，扩大语料则增加步数。IsoFLOP试验比较这两种配置在相同预算下的loss，最优点才是配比证据。只看更大模型成绩更高，无法判断它是不是预算最优。

拟合指数还依赖数据质量、tokenizer和试验区间。把同一套系数直接移到自己的中文领域小模型，可能同时错估数据效率和计算量；更合适的用法是借鉴对照方式，区分容量不足、训练不足和数据重复。
