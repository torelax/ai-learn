# DeepSeekMath 补充解读

> 预训练、SFT 和 GRPO 各自改变了哪部分能力？以下为直觉解释与应用延伸，论文内容见 [精炼主笔记](DeepSeekMath详解.md)。

## 预训练、SFT 和 RL 改变不同环节

网页与代码继续预训练提供知识和模式；SFT 教会解题表达与工具接口；RL 改变已有回答的概率分配，并通过采样探索新的轨迹。三者会相互影响，但不能拿最终 MATH 分数单独证明 GRPO 产生了全部数学能力。

## Maj@K 与 Pass@K 的差异尤其值得记

Pass@K 关心 K 次中是否至少有一个正确答案，Maj@K 关心投票是否选中正确答案。论文观察到 RL 更明显提升后者，提示训练可能主要集中正确模式的概率质量。要讨论能力上限，应同时控制采样预算并检查多样性。

## 120B 与 500B 为什么都正确

前者是挖掘出的数学语料规模，后者是混合继续预训练消耗。数据集大小、重复训练量和总 token 配比属于不同字段。自己做小领域模型时也应分别记录，否则很容易错误估算独立数据量和训练强度。


## 用一个具体场景串起来

同一道题采八个解答，其中两条正确。SFT可以把两条正确轨迹当示范；GRPO则用同题候选的相对奖励，增加好轨迹概率、减少坏轨迹概率。若八条都错，规则正确性在这一组内难形成有效区分。

因此更强数学预训练不是可有可无的前置步骤：它改变采到正确路径的机会。RL提高Maj@K而Pass@K改善有限时，更像在现有解法分布中重新分配概率；要讨论能力边界，需要检查大预算下仍能否出现新成功题。
