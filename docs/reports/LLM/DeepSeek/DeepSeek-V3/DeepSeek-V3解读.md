# DeepSeek-V3 补充解读

> MTP 的训练收益与部署收益为什么要分账？以下为直觉解释与应用延伸，论文内容见 [精炼主笔记](DeepSeek-V3详解.md)。

## MTP 有两笔收益账

训练时额外预测提供更多监督，可以改善主模型表示；推理时额外模块又可提供 speculative draft。前者不要求部署 MTP，后者依赖草稿接受率与验证成本。不能把训练消融提升直接当成推理加速倍数。

## 路由均衡是控制回路

偏置根据负载上调或下调，相当于让专家选择同时考虑适配程度与拥堵情况。它把容量管理从语言建模梯度中分离，但更新过快会震荡、过慢会响应不足。V3 仍保留小型序列约束，也说明完全局部的均衡不是唯一目标。

## 低成本数字的正确使用方式

正式训练 GPU 小时是可比较的技术指标，前提是清楚包含哪些阶段。研究试错、数据工作、设备折旧和服务成本不是同一账目。对个人实验更可迁移的启发是：先找实际瓶颈，再决定精度、并行和 batch；不必机械复制大集群的每一个组件。


## 用一个具体场景串起来

训练时从位置t预测更后面的token，迫使主干保留对未来有用的表示；部署时MTP另可充当draft，用主模型验收。即使不部署draft，前一种训练收益也可能存在。

若接受率低，额外草稿和验证会抵消加速。训练消融的准确率变化不能换算为服务吞吐，MTP模块存在也不意味着每次请求固定快一倍。
