# DreamCraft3D：补充解读

> 为什么一张好图不能直接变成好资产？以下为直觉解释与应用延伸，论文内容见 [精炼主笔记](DreamCraft3D详解.md)。

## 几何和纹理为什么分开优化

几何决定不同视角之间的对应关系，纹理决定表面外观。如果两者同时被一个偏好单张漂亮图片的先验牵引，模型可能通过错误几何作弊。先固定相对一致的形状，再改善外观，可以缩小后阶段的自由度。

![两阶段与自举反馈](figs/S4-F2-01.png)

图中的自举会把当前多视角渲染变成下一轮先验的训练数据。好处是先验逐渐理解这个具体物体，代价是其错误也可能被继承，因此依赖前阶段几何质量。

## 一张正面好看不代表资产可用

实际 3D 资产还需要检查背面、遮挡、网格拓扑、薄结构、材质和不同光照。论文中的参考图 PSNR 很高，但如果用途是游戏或 CAD，这只是完整质量目标的一部分。

## 与 LLM 系列如何关联

它体现的是利用已有大模型先验、可微渲染与闭环合成数据解决新任务，不是一个语言模型报告。保留在系列中有助了解团队研究范围，阅读时应按生成式视觉和 3D 基础补充知识。

## 用一个具体场景串起来

设想参考图是一把只有正面可见的椅子。逐视角追求好看的二维图，背面可能又长出一套椅腿；参考图像素监督也无法排除它。视角条件先验与逐步扩展视角先控制结构，纹理阶段才有可靠载体。

自举的关键不是让模型反复表扬自己，而是改变监督来源：当前多视角渲染提供一致性，二维先验补细节，再用更好的渲染训练下一轮专用先验。若几何一开始错了，固定几何后的纹理再漂亮也不能修好结构。
