# DeepSeek-VL：补充解读

> 视觉训练为何会干扰原来的语言模型？以下为直觉解释与应用延伸，论文内容见 [精炼主笔记](DeepSeek-VL详解.md)。

## 学到视觉能力为什么会损失语言能力

所有数据最终都通过同一个语言骨干更新参数。图像描述的词汇、句式与推理深度和一般文本不同，长期只看这类分布，就可能覆盖原来的能力。保留纯文本不是简单防遗忘技巧，也是在明确产品需要同时服务哪些输入分布。

## 两个视觉编码器不等于重复计算

语义特征希望对细节变化保持稳定；OCR 则要求一个笔画差异也能改变输出。两种目标之间有张力，因此高分辨率局部分支可以补足对比学习表示的盲点。

图中训练顺序意味着适配器只是接口，核心能力还需要骨干参与学习。若只训练 projector 却期待复杂图表推理大幅改善，通常是在要求一个容量很小的模块承担整个系统的任务。

## 复用配方时先确定目标

70% 文本是本文数据和模型下的实验选择，不是多模态训练的通用常数。做文档助手应单列 OCR、小字、表格结构和长页评测；做日常助手则还要观察纯文本退化。最合适的比例来自这些目标之间的实测权衡。

## 用一个具体场景串起来

如果图文数据多数是“图里有什么”，训练会反复强化短描述，分布与复杂纯文本任务不同。增加视觉样本同时减少语言梯度，可能让视觉分变好、语言能力退化；这不是视觉编码器参数多就必然发生的物理定律。

混合比例和解冻范围分别控制学什么、谁来学。只训练小适配器无法充分改变LLM内部处理；主体解冻后又需要文本约束。报告的三阶段和模态预热是在处理这两个不同问题。
