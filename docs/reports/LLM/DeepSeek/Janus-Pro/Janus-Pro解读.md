# Janus-Pro：补充解读

> 这篇最值得学的是哪种训练预算重排？以下为直觉解释与应用延伸，论文内容见 [精炼主笔记](Janus-Pro详解.md)。

## 这篇适合学训练预算分配

最直观的改变不是新增层，而是把容易任务放到便宜阶段，把骨干全面更新的预算留给复杂任务。类似思路也适用于语言训练：先确认接口已经学会，再决定是否需要用昂贵全参阶段反复学习同一种简单映射。

## 大量合成数据改善的是哪些分布

合成图像更干净、更美观，可以减少数据噪声；也可能压窄风格、把上游生成器的偏差复制过来。应分别测试审美、多样性、真实世界细节及罕见概念，避免只根据损失下降判断数据质量。

## 如何理解“超过 DALL-E 3”

论文比较的是特定测试集与评测协议下的数字。GenEval 强调组合遵循，对高分辨率质感、字形、编辑、人物一致性和交互流程覆盖有限。将论文结论用于选型时，应把这些缺失维度补上。

## 用一个具体场景串起来

类别名到图像的基本依赖可以在冻结LLM、训练新模块时先学。如果继续在昂贵的主体解冻阶段大量重复，可能占掉本应学习复杂提示的计算。Pro把简单阶段前移，是把不同难度放在合适更新范围。

合成美学数据还能减少噪声，但可能改变画风与主体分布。GenEval提高主要说明提示约束满足更好，不能仅凭该分数推断所有照片真实性、细小文字或人物细节都更好。
