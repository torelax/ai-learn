# DeepSeek-R1：补充解读

> 长思考、探索和蒸馏分别是什么？以下为直觉解释与应用延伸，论文内容见 [精炼主笔记](DeepSeek-R1详解.md)。

## 先分清三个模型与两种问题

R1-Zero 问“从 base 直接做可验证奖励 RL，会发生什么”；R1 问“怎样把推理能力变成可读、可用的通用助手”；蒸馏模型问“如何把大模型产生的轨迹迁移到小模型”。三者的训练路径不同，不能把 R1 的所有行为都归给纯 RL。

## Aha moment 不是算法模块

模型在训练中出现自检、改换路径等行为，是观察到的现象，不是每道题必须插入固定口头禅。评估时关注答案正确率、有效推理与 token 成本，而不是生成了多少“等等，让我重新想想”。

## 蒸馏与 RL 的预算不能直接比较

小模型用大模型筛选后的轨迹做 SFT，获得的是已被教师计算筛过的数据。如果把这一步称为低成本，应同时说明教师生成成本是否计入。论文给出的比较在特定基座、数据和预算下成立，并不证明小模型强化学习永远没有价值。

训练中 AIME 2024 的平均 pass@1 从 15.6% 升至 71.0%；多数投票进一步达到 86.7%。前者估计单次回答成功率，后者消耗多次生成预算，不能直接当成同一指标。

## 用一个具体场景串起来

一条长轨迹可以中途发现错误并改路；64条短轨迹多数投票则彼此独立。两者都增加计算，却改变不同的搜索结构，所以不能只按输出token数认为等价。

蒸馏再把强教师已找到的轨迹变成学生监督，降低学生从零探索的难度。它证明轨迹可迁移，不证明小模型自行RL永远无效；基础检查点、奖励和预算会共同改变比较。
