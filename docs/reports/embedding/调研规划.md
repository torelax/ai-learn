# Embedding 调研规划

> **基调**：主文做成**可读通、可回查**的长篇调研（**万字起步，目标十万字量级**），系统讲清 Embedding 的历史、原理、表示范式、训练、评测、应用与工程；在此之上用**专题文档**把关键单点挖透（如 BGE-M3、Embedding 蒸馏、难负例工业实践等）。  
> **目录**：本文档与全部 Embedding 调研产出位于本目录；蒸馏总论在 `../distillation/`。

---

## 1. 目标与非目标

### 1.1 目标

读完主文 + 必要专题后，读者应能独立回答：

1. Embedding 从 BoW 到 LLM / 多模态骨干经历了哪些范式切换，各自解决什么问题。  
2. Dense / Sparse / Multi-Vector，以及 Bi-Encoder / Cross-Encoder / Late Interaction，分别是什么、何时用。  
3. 对比学习、指令、hard negative、蒸馏、MRL 等训练积木如何组装成一条生产配方。  
4. 文本检索、RAG、图搜图、文搜图、视觉文档检索等任务在表示与流水线上的差异。  
5. 如何读榜（MTEB / C-MTEB / BEIR / ViDoRe / MMEB）、如何设计自有评测、如何避免数据污染。  
6. 开源系列（BGE / E5 / Jina / Qwen3-Emb…）与闭源 API 的能力边界，**以机制理解为主，不以「选哪个现成模型」为终点**。

### 1.2 非目标

- 不写成「每周换模型名」的选型小报。  
- 不在主文里堆无法验证的分数排行（榜单只作对照，口径必须写清）。  
- 不把 LLM 生成式蒸馏（OPD / MiniLLM）与 Embedding 蒸馏混为一谈（可交叉引用蒸馏目录）。

## 3. 主文扩写大纲（对标十万字）

现有主文约 **五千汉字量级骨架 + 时间线 model card**，结构可用，但多数章节仍偏「纲要」。按下列章节**加深**，而不是另起炉灶改名。

| 章 | 现有状态 | 扩写要求（写什么才算「够深」） |
|----|----------|------------------------------|
| **1 执行摘要** | 有 | 保留；随后文更新关键数字与结论，避免与专题冲突 |
| **2 发展历程** | 时间线较丰 | 每个时代补：动机 → 代表性方法机制 → 局限 → 如何被下一时代替代；BERT 后按系列（SBERT/DPR/ColBERT/CLIP/E5/BGE/LLM-Emb）写「演进因果」而不只是表 |
| **3 理论基础与表示范式** | 偏短 | 数学定义、相似度、InfoNCE 推导级讲解；三范式与三交互**对照图+反例**；与 Fusion/Rerank 的边界 |
| **4 架构分类** | 表为主 | 骨干（Encoder/Decoder/VLM）× 交互 × 模态 三维表；「骨干≠交互」专节（对标 FAQ） |
| **5 训练与数据工程** | 有框架 | **独立成「可照着做」的深度**：弱监督/合成数据、指令模板、温度与 batch、假负例、多阶段课表；指向「难负例专题」 |
| **6 评测** | 表为主 | 每类任务「测的是什么能力」；公开榜陷阱；自建评测协议模板 |
| **7 应用全景** | 矩阵有 | 每类应用：输入输出、索引形态、失败模式；RAG / 推荐 / 去重 / 多模态检索分写 |
| **8 Pipeline 工程** | 有 | Hybrid、RRF、rerank、延迟与成本账；与向量库章节衔接 |
| **9 文本模型全景** | 有 | 改为「机制族」叙述 + 代表系列深读索引（BGE/Jina/Qwen3…）；分数表降级为附录 |
| **10 多模态与专用** | 有 | 对齐图文综述四类；图搜图 vs 文搜图专节；ColPali 族；代码/领域 embedding |
| **11 蒸馏与压缩** | 提纲 | 主文只保留版图；细节全部下沉 **《Embedding蒸馏技术详解》专题** |
| **12 向量库与部署** | 有 | ANN、量化、MRL 截维、端侧 ≤0.6B 约束与训练视角（挂接行动线，避免变选型文） |
| **13 前沿与开放问题** | 有 | 每条附「未解问题 / 可做实验」 |
| **14 实践选型指南** | 有 | 改成「任务→表示→训练配方」决策树；弱化品牌名堆砌 |
| **15 参考文献** | 有 | 与 `资料清单` 同步，按章编号 |

**写作纪律**

1. 先机制后品牌；先公式/图后表。  
2. 每个重要概念至少一处「错误用法」警告。  
3. 跨文档只保留相对链接；蒸馏总论用 `../distillation/...`。  
4. 扩写可按章分 commit；HTML 用 `convert_embedding_report.py` 重生。
