# Jina-v2 补充解读

> 本页区分论文结果与进一步的理解、工程取舍。

## 输入可计算与信息可检索

ALiBi 在任意距离定义注意力偏置，避免直接越过有限位置表；这只解决位置表示的一部分问题。要检索末尾细节，模型仍需在注意力和 pooling 中保留它。MLM 外推稳定是有用证据，却不是任意长文检索任务的保证。

## 长文单向量与切块的取舍

整篇表示便于匹配主题，局部片段更容易保留罕见细节。若用户问具体数字，平均池化可能稀释证据；若用户找整篇主题，切块又可能缺全局语境。可同时评估整篇、片段与层级检索，不必把长窗口视为完全替代切块。

## ALiBi 与 RoPE 的比较需要控制条件

后续 v3 更强，还同时改变了骨干、语言、数据和训练阶段。不能用两个最终模型的差值证明某种位置编码普遍更好。要归因，至少应固定其余因素做受控对照。
