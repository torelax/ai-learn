# Jina-ColBERT-v2 补充解读

> 本页区分论文结果与进一步的理解、工程取舍。

## 多投影头与直接截断不同

本篇明确报告采用非共享权重的多个线性头，推理选择哪个头就使用哪个映射。这不同于 Jina v3 将同一个向量直接截短。改变投影头通常需要重新编码或至少重新投影文档，不能把 128 维索引切成前 64 维就假设等价。

## MASK 的“可见”与“保留输出”不同

查询增强先增加 MASK 位置，这些位置输出可以参与 MaxSim；注意力 mask 又决定真实词能否看见它们。二者是不同开关。只对最终输出做 padding mask，并不能复现论文的注意力消融。

## 采样语料的用途与限制

BM25 top-250 加已判相关段落，便于快速测试表示设置，但负例分布不同于全库。它适合做开发消融，最终模型仍应回到完整语料测试。论文保留这一区分，因此不能把消融表的高分直接与主表比较。

## 召回器也能做重排

独立编码和 MaxSim 允许全库索引，也允许对其他检索器给出的候选打分。本篇不是联合编码的列表重排器，但不意味着 ColBERT 不能用于重排。区分架构与流水线角色，才能避免“不是 reranker”造成误解。
