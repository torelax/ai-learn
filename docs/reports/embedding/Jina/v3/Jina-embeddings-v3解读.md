# Jina-v3 补充解读

> 本页区分论文结果与进一步的理解、工程取舍。

## 任务适配器改变什么

同一段话经不同 LoRA 会得到不同几何关系。检索 query 和 passage 的双适配器是共同训练的一对，不是可以随意互换的标签；已有文档库切换适配器时也需重建对应表示。任务路由降低了提示自由度，但仍要求应用正确界定相似性的含义。

## CoSENT 的正确直觉

对标注相似度更高的一对 a 与较低的一对 b，标准 CoSENT 惩罚 exp((s_b-s_a)/τ)。当模型把 b 排得更高，指数变大；方向正确且间隔充足时贡献变小。原文式 (4) 的指数相减形式可能让 log 的参数非正，不能直接照抄成训练代码。主文采用标准形式并明确标注了原文排版问题。

## MRL 节省的是索引侧成本

多前缀共同训练让低维前缀也承担语义任务，不是给坐标标上可解释的重要性名次。推理截断后应重新归一化，并保证查询、文档维数和适配器一致。截断通常不减少骨干编码开销。

## 失败驱动合成值得怎样借鉴

先收集模型真实错例，再生成同类正负对，比笼统扩充随机问答更有针对性。但训练和评测若都由同一模板产生，模型可能只学会模板。应保留自然发生的独立失败集，特别是未修好的实体歧义，避免用合成集的提升替代真实收益。

## 谱系笔记

```text
v2:  双向 ALiBi BERT · 英 · 8K · 两阶段 InfoNCE
  → 双语变体（zh/es/de）
v3:  XLM-R+RoPE · 多语 · Task LoRA×5 · MRL · 失败合成数据
v4:  Qwen2.5-VL-3B · 图文统一 · 单/多向量联合训练 · LoRA×3 · 32K
```

v3 的关键遗产：

1. **用 LoRA 做任务路由** 比纯 instruction 更可运维；
2. **MRL** 成为后续产品默认；
3. **失败驱动合成数据** 进入检索 adapter 标准动作；
4. 为 v4 的「冻结 VLM + 多 LoRA」铺路。
