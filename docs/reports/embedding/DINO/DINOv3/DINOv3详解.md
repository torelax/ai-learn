# DINOv3：用 Gram anchoring 稳定大规模视觉自监督

> DINOv3 扩大纯视觉自监督训练，并用早期教师的 patch 相似性结构约束后期模型，修复长期训练中的局部特征退化。
>
> [论文](https://arxiv.org/abs/2508.10104) · 本文依据 v1 · [补充解读](DINOv3解读.md) · [代码](https://github.com/facebookresearch/dinov3)

## 摘要

扩大模型和训练时间通常能提高整图分类，却不一定改善局部视觉表示。DINOv3 发现，长时间自监督训练后，patch 特征会失去局部一致性，分割等密集任务反而退步。作者以约 17 亿张筛选图像和 7B 视觉模型扩大训练，并引入 Gram anchoring：匹配学生与早期教师的 patch 两两相似度，而不强迫每个向量保持不变。结合高分辨率后训练和蒸馏，模型在全局及密集任务上均有提升。它的核心是视觉特征；文本对齐属于额外训练阶段。

## 引言

长期扩大视觉自监督可以提高全局语义，却可能破坏局部 patch 的一致性。本文同时推进数据和模型规模、局部特征正则与后训练，目标是提供可冻结使用的整图和密集视觉表示，并蒸馏成不同预算的模型族。

## 相关工作

### 自监督学习

遮挡像素或潜变量预测提供图内监督；DINO 等判别方法匹配视图，iBOT 结合全局和 patch 目标。DINOv3 延续该组合，并处理长时间训练中的全局—局部失衡。

### 视觉基础模型

监督、CLIP 式弱监督和纯视觉 SSL 都可扩大训练。SigLIP2、PE 等具有强全局能力，本文研究不依赖图像描述的特征，并保持密集预测能力。

### 密集 Transformer 特征

检测、分割、几何、机器人及 VLM 都依赖 patch 表示。SAM 蒸馏等可增强密集特征，Gram anchoring 则使用模型自身早期 checkpoint 的关系结构，无需另加分割标签。

## 大规模无监督训练

### 数据准备

原始图像池约 17B，来自公开 Instagram 帖子。作者结合三部分数据：基于 DINOv2 表示进行分层聚类和平衡采样的 LVD-1689M、基于精选种子的相似图像检索集，以及公开视觉数据集。10% 的训练批次只来自 ImageNet-1k，其余使用其他来源混合批次。数据消融显示，没有单一整理方式在所有下游任务上最优。



分层聚类为五层，从 200M、8M、800K、100K 到 25K 簇；均衡采样改善概念覆盖，相似图像检索则照顾常见应用。数据消融使用较短的 200K 步，最终配方结合各来源优势。

### 大规模自监督

初始目标沿用图像级 DINO、patch 级 iBOT 和分布正则：

$$
\mathcal L_{\mathrm{Pre}}=\mathcal L_{\mathrm{DINO}}+\mathcal L_{\mathrm{iBOT}}+0.1\mathcal L_{\mathrm{DKoLeo}}.
$$

教师目标用 Sinkhorn-Knopp 处理，全局与局部裁剪采用专用归一化。7B ViT 使用 patch size 16 和带坐标尺度扰动的 RoPE，改善对分辨率与宽高比变化的适应。训练批量 4,096，每图两个全局裁剪和八个局部裁剪，分别为 256 与 112 像素；warmup 后采用常数学习率、权重衰减和教师 EMA 动量，便于持续训练。

分布式 KoLeo 以 16 样本小组计算，避免大批量下近邻统计失衡。全局与局部 crop 输出使用各自的 LayerNorm；7B ViT 的 RoPE 将 patch 坐标归一化到 [-1,1]，再随机缩放至 [-s,s]，s 取 0.5–2。训练使用 AdamW、256 张 GPU，每批约 3.7M 视觉 tokens。

## Gram anchoring：密集特征正则

### 长训练中的 patch 一致性退化

论文观察到约 200K 步以后，分类继续改善，但 patch 相似性图出现越来越多不相关的高相似区域，分割质量下降。这不同于高范数异常 patch：加入 register tokens 后范数仍可稳定，而局部特征仍逐渐偏向全局语义。

![长期训练中的全局与局部变化](figs/S3-F5-08.png)

图属于论文的训练演化分析。判断视觉表示是否变强，必须同时观察全局读出与局部特征，不能只追踪 ImageNet 分类指标。

### Gram 目标

设一张图有 $P$ 个 patch，学生和 Gram 教师的单位化特征为 $X_S,X_G\in\mathbb R^{P\times d}$：

$$
\mathcal L_{\mathrm{Gram}}=\|X_SX_S^\top-X_GX_G^\top\|_F^2.
$$

Gram 矩阵包含图内所有 patch 两两点积。直接约束关系结构使特征仍可整体改变，只要局部相似性不被破坏。Gram 教师最初取局部质量较好的早期 checkpoint；它与持续更新的普通 EMA 教师承担不同角色。

论文为节省成本，在 1M 步后才加入该目标，仅作用于全局裁剪；每 10K 步将 Gram 教师更新为当时的 EMA 教师。即使局部特征已退化，这一阶段仍能较快修复。总目标继续保留 DINO、iBOT 和 KoLeo，避免只维护局部结构而放弃全局学习。

![Gram 约束后的指标变化](figs/S4-F8-01.png)

论文报告加入约束后首个 10K 步就可观察到密集任务收益；高分辨率教师进一步改善结果。实际结果来自完整目标组合，不能解释为只匹配 Gram 矩阵便能从零训练通用模型。

精炼阶段目标保留加权的 DINO、iBOT、DKoLeo，再加 Gram 损失。加入后 iBOT 更快降低，DINO 损失变化较小，支持局部一致性与全局判别的部分独立性。

### 利用更高分辨率特征

Gram 教师先以两倍分辨率处理图像，再将特征图双三次下采样到学生网格，从而提供更平滑且局部一致的关系目标。相比普通 refinement，ADE20K 约再提高 2 个 mIoU 点。选择 100K 或 200K 的早期教师效果相近，使用局部已退化的 1M 教师则更差。



## 后训练

### 分辨率扩展

随后用全局 512/768、局部 112/168/224/336 的混合分辨率再训练 10K 步，并保留 Gram 约束。Gram 约束在这一阶段仍很重要；局部任务随输入分辨率提高继续受益，低分辨率 ObjectNet 则可能略降。

### 模型蒸馏

#### 多预算模型族

固定 7B 教师，训练 ViT-S（21M）、S+（29M）、B（86M）、L（约 300M）、H+（约 840M），并训练 ConvNeXt。学生训练 1M 步，再 250K 步余弦冷却，然后做高分辨率适配；未观察到相同的局部退化，故不加 Gram 约束。

#### 多学生共享教师

![多学生共享教师计算](figs/S5-F12-01.png)

多学生训练共享教师前向，通过进程组通信分发教师结果，使新增学生主要增加自己的训练成本。各学生组需要匹配迭代速度，否则同步会受到最慢组限制。



### 文本对齐

文本对齐另采用 LiT 路线：冻结视觉骨干，在视觉侧增加两层 Transformer，组合 CLS 和平均 patch 表示，再训练文本编码器进行图文对比学习。这个 dino.txt 阶段提供开放词表能力，不能把它归给纯视觉预训练本身。

## 结果

### 密集特征

除特别指出外，骨干冻结，只训练轻量读出，或用非参数匹配。基线包括 DINOv2、Web-DINO、Franca、SigLIP2、PE，以及从 SAM 等蒸馏的 AM-RADIO、PEspatial。

#### 定性与线性探测

PCA 可视化更连贯，局部噪声更少；颜色映射经过挑选，不能单独充当定量比较。语义分割考察 ADE20K、Cityscapes、VOC，深度考察 NYUv2、KITTI，分别使用 mIoU 和 RMSE。

论文覆盖线性分类、实例检索、分割、深度、三维对应、视频跟踪、目标发现，以及作为检测、分割、几何系统骨干的效果；另研究卫星图像领域适配。

| 冻结特征评测 | DINOv2-g | DINOv3-7B |
| --- | --- | --- |
| ADE20K 线性分割 mIoU | 49.5 | 55.9 |
| Cityscapes 线性分割 mIoU | 75.6 | 81.1 |
| NYUv2 深度 RMSE，越低越好 | 0.372 | 0.309 |
| ImageNet 线性分类 | 87.3 | 88.4 |
| ObjectNet | 66.4 | 79.0 |

这些数值来自 DINOv3 本文的统一评测，不能直接拿 DINOv2 原论文其他配置的 86.5 替换其中 87.3。对比还包含 SigLIP 2、PE、AM-RADIO、Web-DINO 等；DINOv3 的优势尤其集中在高质量密集表示和鲁棒性，而非每个分类指标都最高。



#### 三维对应

NAVI 测同一实例跨视角的几何对应，SPair 测同类不同实例的语义对应。DINOv3 对 DINOv2 的 recall 增益分别约 4.3、2.6 个百分点，反映局部特征的多视角一致性。

#### 无监督对象发现

用 TokenCut 在 VOC 和 COCO-20k 上做无标注的对象定位，以 CorLoc 计分。相较既有最佳对照，VOC2007 提高约 5.9 分；高质量局部特征并不只改善有监督预测头。

#### 视频分割跟踪

首帧给定实例 mask，再通过跨帧 patch 相似度传播到后续帧。DAVIS-L 的 J&F 为 83.3，较 DINOv2 高 6.7 分；这不是在没有首帧标注时自动生成整段视频分割。

#### 视频分类

逐帧冻结特征接四层 attentive probe，在 UCF101、K400、SSv2 测动作分类。整体强于旧 SSL，但对动作理解更强的专门视频模型 V-JEPA2 在 SSv2 仍领先。

### 全局图像描述符

#### 分类与域泛化

ImageNet 的 CLS 线性头迁移到 V2、ReaL、R、Sketch、A、ObjectNet 与 C，整体接近强图文模型，ImageNet 本域仍落后 SigLIP2、PE 约 0.7–0.9 分。细粒度 iNaturalist21 达到 89.8，对照 PE 为 87.0。

#### 实例识别

用 CLS 余弦排序 Oxford、Paris、Met 和 AmsterTime，Met 与 AmsterTime 比次优 DINOv2 分别高 10.8、7.6 分。类别识别和实例身份检索分别检验不同粒度的全局信息。

### 复杂视觉系统的基础

#### 目标检测

冻结骨干接约 100M 参数 Plain-DETR，先用 Objects365 再用 COCO 训练解码器；COCO-O 额外测试分布偏移。结果有较强竞争力，但包含高分辨率及解码器预训练，不能视作零训练的检测性能。

#### 语义分割

ViT-Adapter 移除向骨干注入的模块，接 Mask2Former；先 COCO-Stuff、Hypersim，再 ADE20K，冻结骨干达到 63.0 mIoU，与论文所比的最好系统相当。它与前面的 55.9 线性探测属于不同协议。

#### 单目深度

沿用 Depth Anything V2 的合成数据和损失，以四层特征训练 DPT，骨干冻结；在 NYUv2、KITTI、ETH3D、ScanNet、DIODE 检验真实图像的零样本相对深度。多数指标领先对照，DIODE 的 ARel 是例外。

#### VGGT 三维几何

把 VGGT 的 DINOv2-L 换成 DINOv3-L，匹配输入 token 数后继续原训练，骨干在此实验参与微调。相机姿态、多视角重建和双视角匹配均改善；不能概括整篇所有应用都冻结骨干。

## 完整模型族评估

### Vision Transformer

各模型按相同输入序列长度比较，patch16 用 512 对照 patch14 的 448。ViT-L 的 ADE20K 为 54.9，接近 7B 的 55.9；H+ 在多项评测上接近八倍参数的教师，但没有每任务无损保证。

### ConvNeXt

T/S/B/L 版本适应卷积设备。低分辨率 ImageNet 可能略低于监督同规格模型，但分辨率提高后更稳定，密集任务显著增强，如 CNX-T ADE20K 42.7 对照 24.8。

### dino.txt 零样本

额外文本对齐后评测零样本分类、COCO 双向检索和开放词表分割。局部语义对齐较强，全局任务仍可低于 SigLIP2、PE；这些成绩属于新增图文训练阶段。

## 遥感数据

### 预训练与基准

卫星版本单独在 Maxar RGB 的 SAT-493M 上训练，100K 步预训练、10K Gram、8K 高分辨率适配；其后也蒸馏 ViT-L。这是另一领域模型，不是 Web 版本在未见数据上的零样本结果。

### 树冠高度

冻结骨干训练 DPT，在 SatLidar1M、Neon、São Paulo、Open-Canopy 测高度 MAE。7B 卫星模型使 Open-Canopy MAE 从既有 2.42 降至 2.02，小学生在部分测试还更好。

### 地球观测任务

GEO-Bench、LoveDA、iSAID、DIOR 覆盖分类、分割与检测，论文在十五项中的十二项获得较强或领先结果。卫星专域训练更利于高度等度量任务，Web 模型在部分语义任务已很强，领域数据价值取决于目标。

## 环境影响

按 PUE=1.1、美国平均电网强度及 GPU 额定功率估算，单次预训练约 47 MWh；整个项目约 9M GPU-hours、2,600 吨 CO₂e。项目估计包含试验而不限最终单模型，且不覆盖制造、处置等全生命周期。

## 结论

大规模自监督可兼得较强全局与密集表示，但需要额外维护局部一致性。Gram anchoring、分辨率后训练及蒸馏共同构成完整方案。附录还分析 register、注意力偏置和异常特征，并补充各应用的训练协议；数据与算力可复现性以及复杂下游头成本仍是实际边界。
