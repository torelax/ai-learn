# DINOv2 补充解读

论文内容见 [DINOv2 详解](DINOv2详解.md)。

## 为什么它属于 Embedding 阅读路线

DINOv2 直接提供可比较的视觉向量，适合图像近邻、去重、聚类和视觉候选挖掘。MegaPairs 用它寻找视觉形态相近的图像，恰好说明它与 CLIP 的语义空间可以互补。但没有文本编码器与之对齐时，不能拿一个独立文本模型的向量直接做点积。

## CLS 与 patch 应怎样选

CLS 适合整图分类和粗粒度检索；patch 保留局部结构，可以用于区域匹配、对应或密集预测。把所有 patch 平均池化虽然省空间，却可能抹去小物体和局部关系。若任务是“同款零件”或“页面中的局部图案”，应比较全局与局部表示，并控制裁剪及图像尺寸。

## “冻结可用”节省了什么

它意味着下游可以先训练轻量预测头，不必把整个视觉模型重新训练。省下的是适配成本，不是预训练成本，也不意味着无需任何标签。ImageNet 线性探测仍使用带标签样本训练分类器；只有 kNN、无监督聚类等使用方式才对应另外的监督条件。

## 数据筛选既是提升来源，也是先验

用精选种子找近邻让网络数据更接近有价值的视觉概念，同时也可能放大种子的领域偏向。迁移到医疗、遥感或工业图像时，增加数据量未必能覆盖关键细节。更有信息量的比较是原始数据、领域种子采样和混合采样三者在同一目标集上的表现。
