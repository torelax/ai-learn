## 谱系速览

```text
稠密单向量：  E5 → GTE → gte-Qwen2 / E5-Mistral
              Nomic（长上下文开源复现）
              LLM2Vec（Decoder→Encoder 适配）
              Conan-v1（BERT + DHNM + CBB）→ Conan-v2（从零 LLM + soft-mask）
              QZhou（双向 Qwen2.5-7B 多任务冲榜）
              Token-Prepending（零训练因果补丁，非冲榜模型）

多向量迟交互： ColBERT → ColBERTv2 → PLAID
                 └──────────────→ ColPali → ColQwen2 → ColQwen2.5 → ColQwen3*

Jina：  v1 → v2 → v3 ──→ v4（MLLM）→ v5-text → v5-omni（Locked Towers）
                    └─ jina-clip v1/v2（CLIP dual-tower，并行线）

数据侧：  BM25/in-batch → ANCE（异步全局）→ RocketQA 去噪
              → NV-Retriever（正例锚定）→ Conan DHNM（动态替换）
          正例增强： EDA/回译 → LLM-DA（改写+TFF+BSS）→ QZhou 合成
          视频语料： ActivityNet Captions → DeVE-QA（QA+定位）

领域专用： SPECTER/SPECTER2（引用图）→ MedCPT（点击）→ CodeBERT/UniXcoder/CoIR/CodeR
           → LEGAL-BERT/SAILER → YouTube DNN 双塔
           实践综述：领域专用Embedding适配实践（对齐文搜图）
```

`*` ColQwen3 为社区/后续骨干升级，方法论文仍以 ColPali 为准。
