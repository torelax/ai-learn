# MegaPairs：用大规模合成关系数据训练多模态检索器

> MegaPairs 从不同相似性空间挖掘图像对，再让视觉语言模型和语言模型生成连接两张图的检索指令，形成大规模组合检索数据。
>
> [论文](https://arxiv.org/abs/2412.14475) · 本文依据 v1 · [项目](https://github.com/VectorSpaceLab/MegaPairs)

组合图像检索需要根据“参考图像＋修改意图”寻找目标图，而自然网页上的共同出现图像往往数量不足、关系单一或互为重复。MegaPairs 从通用图像库主动挖掘有关系但不重复的图像对，用模型解释差异并生成指令，得到超过 2,600 万个图像对的训练集合，再训练 CLIP 和 MLLM 两类 MMRet 检索器。结果表明，关系多样且能指导区分的数据比单纯扩大弱配对数据更有效；其局限在于合成教师错误、图像库偏差，以及跨任务评测配置并不完全一致。

## 从网页共现到多空间挖掘

MagicLens 等工作利用同网页图像构造开放指令，但共现不一定意味着有用的可检索关系。MegaPairs 从 Recap-DataComp-1B 的 20M 带描述图像子集出发，在三个空间检索邻居：EVA-CLIP 图像特征捕捉视觉语义，DINOv2 特征捕捉视觉形态，EVA-CLIP 文本特征捕捉描述语义。

![MegaPairs 数据合成流程](figs/S2-F1-01.webp)

同一查询图片在不同空间里可能找到相同主体、相似外观或相近情境的对象。融合这些邻居扩大关系类型，避免训练仅学会一种“相似”。论文以 0.8–0.96 的相似度区间控制弱相关和近重复样本；该数值属于其特征空间和挖掘配置，不是跨模型通用阈值。

## 从图像关系生成检索指令

InternVL2-26B 分析图像对的共同点和差异，LLaMA3-8B 据此生成开放式指令。每个图像对生成至少三种指令，并选取五个难负例，形成 $(I_q,t,I_d^+)$ 与负候选。

例如查询既保留参考图中的主体，又要求改变某个属性，模型就必须利用文字区分视觉上相近的候选。难负例来自检索邻居，使训练不只依赖“找到主题相似图片”。最终集合包含 26,235,105 个图像对；图像对数与多指令展开后的训练条目数应分开理解。

## MMRet：两类模型共享匹配目标

CLIP-based MMRet 采用图像和文字表示融合，提供 Base/Large 规格；MLLM-based MMRet 使用 LLaVA-1.6-Mistral-7B，将图文联合输入，取末尾表示并归一化。二者都优化带批内负例和难负例的对比损失：

$$
\mathcal L=-\log\frac{\exp(s(q,d^+)/\tau)}{\exp(s(q,d^+)/\tau)+\sum_{d^-\in\mathcal N}\exp(s(q,d^-)/\tau)}.
$$

论文温度设为 0.02，初始学习率为 $5\times10^{-6}$ 并线性衰减。不同模型共享数据构造思路，但参数量、联合理解能力和编码成本不同。

## 组合检索与通用表示评测

CIRCO 使用较大候选库并允许多个相关目标，主指标为 mAP@5；CIRR 报告完整候选库 Recall@1 及小集合的 subset Recall@1；FashionIQ 关注服饰属性修改；GeneCIS 考察条件图像相似性。不能把这些指标合称为统一准确率。

MMRet-MLLM 在 CIRCO 的 mAP@5 达到 42.2，论文对照 MagicLens-L 为 34.1，即增加 8.1 个百分点。论文还报告 CIRR 与 GeneCIS 的收益，但并非每个模型在每个数据集上都领先，FashionIQ 的结果尤其应按具体配置阅读。

在 MMEB 36 个数据集的零样本评测中，MMRet 总分为 44.0，对照 OpenCLIP 39.7、UniIR 42.8。这里的“零样本”指没有在 MMEB 训练集进一步微调，模型已经用 MegaPairs 训练。

进一步使用 MMEB 的约 662K 条 IND 数据训练，LoRA rank=32、批量 192、学习率 $5\times10^{-6}$、一个 epoch，得到总体 64.1。论文正文的“提高 9.1”比较的是 LLaVA 低分辨率 VLM2Vec 的 55.0；附录另列 Phi 版本 60.1，而 VLM2Vec v3 的高分辨率版本为 62.9。比较时必须绑定具体版本和骨干，不能把 9.1 当成对所有 VLM2Vec 的领先幅度。

## 数据质量、规模与难负例消融

![训练数据规模的影响](figs/S4-F2-01.png)

在相同 CLIP Base 起点的实验中，500K MegaPairs 样本已超过使用 36.7M MagicLens 数据的对照。这个约 70 倍的差异描述训练样本量，并不等于总计算或合成成本降低 70 倍。随着训练数据增加，多种检索指标继续改善。

作者在 1M 数据和固定训练步数下比较挖掘空间：描述空间是较强的单独来源，组合空间进一步提高关系多样性；三空间联合取得更稳健的结果。难负例优于不使用难负例或只依靠简单替代负例的配置，支持“相似但不满足指令”的监督价值。

## 附录与结论

附录提供图像关系分析、指令生成提示、训练设置、分数据集结果与定性示例。主要结论是：通用图像库经过关系挖掘和指令合成，可以形成规模化的多模态检索监督，且收益能够迁移到部分其他表示任务。

合成质量仍取决于 VLM 是否看对属性、LLM 是否把关系说清、难负例是否真的不相关；原始图像库的过滤也不完美。论文只探索了有限挖掘器与训练配置，不能据此认为更多合成数据必然持续提升任意检索任务。
