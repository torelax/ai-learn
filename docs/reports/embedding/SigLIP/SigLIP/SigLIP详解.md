# SigLIP：以成对 sigmoid 损失训练图文表示

> 将图文匹配从 batch 内的 softmax 选择改为独立的成对二分类，使损失容易分块计算，并改善较小 batch 下的训练。
>
> [Sigmoid Loss for Language Image Pre-Training](https://arxiv.org/abs/2303.15343v3) · ICCV 2023 · [big_vision](https://github.com/google-research/big_vision)

## 论文简介

CLIP 的对称 softmax 需要在整批相似度上归一化，大 batch 往往带来更多负例，也增加分布式通信和显存压力。SigLIP 将每个图文组合视为独立正负分类，使用可学习尺度和偏置的 sigmoid 损失；再通过设备间分块交换表示，逐块累计损失，避免物化完整相似度矩阵。

论文分别研究从头或解冻视觉塔的 SigLIP，以及冻结预训练视觉塔的 SigLiT，并把 batch 推至百万。结果显示较小 batch 时 sigmoid 优势更明显，但扩大到约 32K 后收益趋缓，极大 batch 有时反而退步。研究重点是目标函数及训练效率，并不证明所有图文任务都只需一个固定 batch 规模。

## 背景与比较设置

CLIP/ALIGN 用图文对比学习获得可迁移表示；LiT 冻结已有视觉模型，只训练文本侧对齐。本文分别把 sigmoid 应用于两种训练路径，避免把已有强视觉模型的知识当作从零训练收益。

英语 SigLIP 使用 WebLI 图文数据，主要消融采用 ViT-B/16、224² 输入、32K SentencePiece 词表和最多 16 个文本 token。多语 mSigLIP 扩展到超过 100 种语言，以 ImageNet 零样本分类和 XM3600 的 36 语言检索评测。

## 从 softmax 到成对 sigmoid

设图像和文本的归一化表示为 $u_i,v_j$，正配对 $y_{ij}=+1$，其余 $y_{ij}=-1$，学习尺度 $t=\exp(a)$ 和偏置 $b$：

$$
s_{ij}=t\,u_i^\top v_j+b,\qquad
\mathcal L=-\frac1B\sum_{i=1}^B\sum_{j=1}^B\log\sigma(y_{ij}s_{ij}).
$$

与 CLIP 不同，这里没有跨候选的 softmax 分母，也不需要再对转置矩阵算第二份方向损失。每项都在判断一个配对是否成立；但若仍使用全部批内组合，计算项数依旧是 $B^2$，并没有消除负例计算。

每批只有 $B$ 个正对，却有 $B(B-1)$ 个负对。可学习偏置帮助模型从合适的负例先验出发。论文消融使用 **$t=10$、$a=\log10$、$b=-10$** 初始化；方法段有一句将 $a$ 直接写成 10，与后文消融的明确设置不一致，这里采用后者。

## 分块实现：累计独立项

![原论文图 1：交换负例表示后继续累计](figs/S3-F1-02.png)

每个设备先处理本地正对及负对，再轮换其他设备的表示，计算新的负对块。若全局 batch 为 $B$、设备数为 $D$、局部 batch 为 $b_l=B/D$，峰值相似度块从 $B^2$ 降至 $b_l^2$。设备间仍需通信，只是采用环式 collective permute 等分块方式；这不是“训练完全不依赖其他样本”。

## Batch 扩展与代表性结果

![原论文图 2：三种训练设置的 batch 扩展](figs/S3-F2-01.png)

图左为冻结视觉塔的 SigLiT，中间为 SigLIP，右侧为多语 mSigLIP。SigLiT 使用约 180 亿 seen examples，SigLIP 约 90 亿，多语约 300 亿；这是累计训练样本次数，不能当作独立数据集大小。

SigLiT 在 batch 小于约 16K 时明显优于 softmax，随规模增加差距缩小；百万 batch 可以训练，但 32K 后收益有限。SigLIP 的 sigmoid 峰值约在 32K，softmax 需要更大的 batch 才达到接近效果，继续放大则两者都可能下降。训练样本数固定时，大 batch 意味着更少参数更新；论文也通过训练时长实验说明充分优化的重要性。

| 设置 | 硬件与时间 | ImageNet 零样本 top-1 |
|---|---|---:|
| SigLiT，冻结强视觉骨干 | 4 TPU-v4，2 天，batch 20K | 84.5% |
| SigLIP，解冻已有 B/16 视觉权重 | 16 TPU-v4，3 天，batch 16K | 71.0% |
| SigLIP，从头训练 B/16 | 32 TPU-v4，5 天，batch 32K | 73.4% |

84.5% 包含预训练视觉骨干的已有知识，不能描述为四块 TPU 从零学出的 CLIP。多语表中 XM3600 平均检索从 batch 32K 的 34.9 降至 240K 的 32.7，也说明更大的负例池不保证更好。

## 优化、负例比例与噪声消融

大 batch 容易出现梯度尖峰。将 Adam/AdaFactor 的二阶动量 $\beta_2$ 从 0.999 调为 0.95，能更快响应变化并稳定论文训练。解冻视觉骨干时，移除该骨干的 weight decay 也有帮助。

负例消融中，随机删掉负例以“平衡正负”会降低质量；只保留容易负例更差；保留较难负例更接近完整目标，匹配累计 pair 数后还可有收益。这支持有效负例比简单数量平衡更重要，却不意味着所有最高分负例都安全——其中仍可能有假负例。

偏置实验显示 $b=-10$ 明显优于无偏置或不合适初始化。噪声实验对训练配对进行受控破坏，sigmoid 在所测噪声条件下更稳健；这种结论限定于实验注入的噪声，不能替代真实网页数据清洗。

## 结论与局限

SigLIP 的贡献是可分解的目标及由此带来的分块实现和实验空间。它拆开了样本 batch、配对数量与正负比例，使研究者能独立检查这些因素。局限包括对批内负例的噪声假设、数据和硬件条件依赖，以及 ImageNet/XM3600 不覆盖所有下游能力。后续 SigLIP 2 在此基础上增加定位、局部自监督和数据配方，超出了单纯替换损失的范围。
