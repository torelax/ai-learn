# SigLIP 补充解读：独立损失项与独立训练样本

> 本页解释 sigmoid 的工程含义与容易混淆的概念。

## 它没有让负例失去作用

独立的是每个图文对的损失项，所有项仍通过同一组编码器参数耦合。增加困难负例会改变梯度和最优表示。没有 softmax 全局分母，不等于 batch 大小无关，更不等于可以只喂正对。

## 偏置与相似度的角色

尺度 t 控制余弦差异被放大的程度，偏置 b 调整整体正负先验。负对远多于正对时，初始把所有 pair 都判作约 0.5 会产生大量纠偏梯度。负偏置减少这种启动冲击。推理检索通常只需比较相似度；sigmoid 值也不应自动当作跨领域校准概率。

## 分块降低峰值显存，不一定降低总工作量

把矩阵拆成块不会减少完整 pair 数，但可避免一次驻留全部矩阵。通信、反向图和重计算开销仍取决于实现。GradCache 则主要处理编码器激活内存，两种方法解决不同部分，可以在系统设计中分别考虑。

## “32K 足够”的正确使用

论文在固定模型、数据和训练预算下看到收益饱和。换成长描述、更难负例或更大模型，最优 batch 可能改变。预算比较应同时报告 seen examples、optimizer steps、实际 pair 数和计算时间，避免只凭 batch 数字归因。
