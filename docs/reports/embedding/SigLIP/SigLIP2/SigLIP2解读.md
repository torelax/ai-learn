# SigLIP 2 补充解读：同一个编码器的不同读出

> 本页进一步解释为何全局检索成绩不能代表全部视觉特征质量。

## Pooling 前后服务不同问题

图文检索往往用 MAP 后的一个向量；分割、深度和 VLM 接口则常用未池化 patch 特征。一个模型可能全局分类很好，却缺少局部定位信息。SigLIP 2 把全局与局部目标放到同一训练中，正是为了减少这一差距。

## NaFlex 不是无限分辨率

它在预设 token 预算内尽量保留长宽比，通过位置插值和 padding 处理不同网格。特别长的截图仍可能被缩小到看不清文字。增加预算会带来注意力与视觉编码成本，因而应在 OCR 细节和吞吐之间选择，而非只说“支持动态分辨率”。

## 不同蒸馏在本篇同时出现

EMA 自蒸馏让学生局部视图匹配教师全局/patch 表示；ACID 则让强教师参与样本选择。前者直接改变训练目标，后者改变训练分布。把它们都简写为“用了蒸馏”会丢掉最重要的方法差别。

## 读综合配方时如何归因

固定版与 NaFlex 在增强和自监督上不完全相同，小模型还额外做数据蒸馏。模型表适合比较发布物能力，却不能孤立证明某项设计贡献。复用时先选与目标任务最相关的一项：文档关注长宽比和细字，定位关注区域监督，检索关注全局几何及数据分布。
