# SigLIP 2：从全局图文对齐到更通用的视觉编码器

> 在 sigmoid 图文训练上加入定位与描述解码、自蒸馏、patch 掩码预测和数据筛选，并提供保留长宽比的 NaFlex 变体。
>
> [SigLIP 2: Multilingual Vision-Language Encoders with Improved Semantic Understanding, Localization, and Dense Features](https://arxiv.org/abs/2502.14786) · 2025 · [代码](https://github.com/google-research/big_vision)

## 论文简介

图文全局对齐擅长类别语义，却未必保留定位、OCR 和像素级预测需要的局部信息。SigLIP 2 在原 sigmoid 目标上组合多种互补监督：用解码器学习描述与区域定位，在训练后段加入局部到全局自蒸馏和掩码 patch 预测，并通过多语数据及主动筛选改善覆盖和小模型质量。

论文发布多尺寸、多分辨率编码器，以及单 checkpoint 支持不同长宽比和 token 预算的 NaFlex。实验覆盖分类、检索、VLM 视觉塔、分割、深度和检测，而不只看 ImageNet。多数对照明显改善，但不同变体的训练配方并不完全相同，多语和公平性收益也不是每项指标均有提升。

## 架构、数据与总体训练

固定分辨率版保持标准 ViT 与学习式位置嵌入，便于替换原 SigLIP。图像与文本使用注意力池化 MAP；文本长度 64，采用 256K 词表的多语 Gemma tokenizer，并转为小写。模型提供 B、L、So400m、g 等尺寸。

数据来自 WebLI，原池约 **100 亿图像、120 亿 alt-text、109 种语言**。训练混合约 90% 英语网页和 10% 非英语网页，并采用缓解敏感属性表示及关联偏差的过滤。全局 batch 32K、Adam 学习率 $10^{-3}$、weight decay $10^{-4}$、梯度范数裁剪 1，累计训练 **400 亿 seen examples**；这一数值包含重复采样。

图中的阶段安排用于控制额外解码和多视图训练的成本。最终发布的是编码器，辅助解码器不随模型作为推理组件使用。

## 图文与解码器监督

起始阶段等权组合 SigLIP 的成对二分类与 LocCa 解码目标。解码器 cross-attend 未池化的图像 token，学习三种任务：整图描述；根据区域描述预测框；根据框生成区域描述。

区域—文字对由网页描述 n-gram、固定类别及开放词汇检测自动构造。描述任务约一半概率采用并行 mask 预测而非纯自回归。三种任务分别前向，解码器损失也按词表分块降低显存。默认 patch 16、图像 256²，对应 256 个图像 token。

这些目标让视觉 token 既承担整图语义，也携带“哪里是什么”的信号，补充全局图文损失无法直接约束的局部结构。

## 自蒸馏与掩码预测

训练完成约 80% 时增加两个视觉自监督项：

- **局部到全局一致性**：EMA 教师看一张全局图，学生看八个局部视图，在 MLP 投影空间匹配表示。
- **掩码 patch 预测**：学生遮住全局视图 50% patch，预测教师在对应位置的特征。

二者基础权重为 1 与 0.25，再按模型尺寸乘额外系数。图文与 LocCa 仍看原始图像，额外增强只用于自监督，减少增强对图文对应关系的破坏。该训练提升的是局部特征，不是把输出全局 embedding 改成多向量检索格式。

## 分辨率适配与 NaFlex

固定分辨率模型从约 95% 训练处恢复，插值位置嵌入，必要时使用 PI-resize 改变 patch embedding，再以目标分辨率完成所有目标训练。

NaFlex 则尽量保持原图长宽比，将高宽调整为 patch 大小的整数倍，并限制 token 总数；不足预算的部分 padding，注意力与 MAP 均忽略这些位置。位置表从 16×16 网格双线性插值到实际非方形网格。

它在约 90% 训练处切换预处理，每 batch 从 $\{128,256,576,784,1024\}$ 采样一个序列长度，延长末段训练。**NaFlex 不采用上述自蒸馏与掩码预测**，这一差异必须保留，不能把所有 SigLIP 2 配方都算到同一个 checkpoint 上。

![原论文图 3：固定分辨率与 NaFlex 的检索曲线](figs/S2-F3-01.webp)

NaFlex 在文档、屏幕和 OCR 类检索，特别是较低 token 预算时更有优势；固定分辨率 B 模型在自然图上可能更强，部分源于后续蒸馏。跨变体比较同时包含预处理及训练目标差异。

## 小模型的主动数据蒸馏

B/16 与 B/32 进一步以较低学习率、无 weight decay 训练约 40 亿样本，只保留 sigmoid 图文目标。ACID 使用教师和当前学生评估样本的可学习性，从更大的 super-batch 中选训练 batch；B/16 典型为 64K 选 32K。

教师为在高质量数据上继续适配的 SigLIP 2 So400m。知识通过“选哪些样本”传递，而非额外强制学生拟合教师 logits。本文将其称为隐式数据蒸馏，不能与常规 softmax/KL 蒸馏混为一谈。

## 分类、检索与 VLM 迁移

下表节选同架构、同分辨率比较。ImageNet 为零样本准确率，COCO 与 XM3600 为表 1 的文→图检索分数。

| 模型 | ImageNet | COCO 文→图 | XM3600 文→图 |
|---|---:|---:|---:|
| SigLIP B/16，256 | 76.7 | 47.4 | 22.5 |
| SigLIP 2 B/16，256 | 79.1 | 53.2 | 40.7 |
| SigLIP L/16，256 | 80.5 | 51.2 | 30.9 |
| SigLIP 2 L/16，256 | 82.5 | 54.7 | 46.5 |

最大 g/16、384 模型 ImageNet 为 85.0。XM3600 多语成绩明显优于原 SigLIP，但仍可能略低于专门多语 mSigLIP；后者英语成绩较弱，体现数据配比的取舍。

作者还固定视觉编码器，接 Gemma 2 2B，在 PaliGemma 式混合任务上训练 **5000 万样本**，再对各下游任务微调；SigLIP 2 整体优于 SigLIP，L 尺度也优于所测 AIMv2。图注曾写“50M steps”，正文明确是 examples，本文按正文口径表述。

## 局部与密集任务

冻结 So/14、384 编码器后，ADE20K 分割 mIoU 从 **40.8 到 45.4**，NYUv2 深度 RMSE 从 **0.563 降至 0.466**；这说明收益进入了未池化局部特征。深度与法线指标越低越好，不能与分割分数同向比较。

RefCOCO 指代表达定位中，L 模型、256 token 的 val 准确率从 **67.33 到 86.04**，仍低于专注该目标的 LocCa 88.34。OWL-ViT 式开放词汇检测中，So/14 的 LVIS rare AP 从 **40.9 到 42.3**。这些任务分别使用训练过的解码器或适配流程，不是直接对全局 embedding 做余弦即可得到结果。

## 文化覆盖、附录与结论

Dollar Street、GeoDE、GLDv2 用于地域与文化分布评测。匹配 L/16、256 模型时，GeoDE 区域 10-shot 从 36.2% 到 44.4%，Dollar Street 零样本从 52.1% 到 55.2%。性别表示偏差指标有所改善，但按收入和地区细分的差异只显示很小或没有改善；不能概括成全面消除了偏差。

附录提供完整 PaliGemma、NaFlex 与文化公平性结果。本文是一套组合训练配方的系统验证：全局对齐、局部自监督、语言定位和主动数据选择互补，但很难把最终全部收益归给单一组件。部署时还需区分模型尺寸、分辨率、NaFlex 与固定版，以及下游任务是否需要额外适配。
