# ViDoRe v2 补充解读

报告内容见 [ViDoRe v2 详解](ViDoRe-v2详解.md)。

## 难度变化比新榜单更值得学

真实用户不会按答案原句提问。构造内部评测时，让问题作者只看到业务背景，再由另一组人员检索并标注证据，可以减少词面泄漏。代价是产生更多无法回答的问题，需要明确标记无答案，而不是强行给每条查询指定一个页面。

## 跨文档问题仍可能只评了页面排序

nDCG@5 能奖励多个相关页面，但没有直接判断五页是否覆盖完整推理链。经济比较问题可能需要两份报告中的不同年份数据；若前五名都来自同一侧，即使部分相关，也无法完整回答。可以另测每个必要证据组是否至少召回一页，再看生成答案的出处和正确性。

## 多语言能力如何定位

“法语查询→英语页面”同时涉及跨语言对齐和视觉文档理解。失败可能来自查询编码、OCR/视觉理解或局部匹配。分别测试同语言查询、人工翻译查询、OCR 文本候选和页面图像候选，才能判断主要瓶颈，而不能从一个平均分推断模型不懂法语。

## 使用时固定版本

v2 原报告包含单语、多语及人工查询任务；其他论文可能使用其中四个数据集。对比数字前要先对齐任务集合、平均方式、页面预处理和模型版本。用相同名字指代不同集合，是视觉检索文献里很容易发生的误读。
