# P-Tuning v2：把深层提示适配到理解与序列标注

> **简述**：冻结主干，在各层加入连续前缀，并训练适合任务的输出头，改善较小模型和复杂 NLU 任务的提示微调效果。<br>
> **paper**：[P-Tuning v2](https://arxiv.org/abs/2110.07602) · [ACL 2022 正式版](https://aclanthology.org/2022.acl-short.8/)<br>
> **code**：[THUDM/P-tuning-v2](https://github.com/THUDM/P-tuning-v2) · **refs**：[Prefix-Tuning](https://arxiv.org/abs/2101.00190)、[Prompt Tuning](https://arxiv.org/abs/2104.08691)<br>
> **backbone**：BERT Large、RoBERTa Large、DeBERTa XL、GLM XL/XXL · **date**：2021-10 预印本，2022 年发表<br>
> **modality / languages**：文本；主要英语全监督 NLU、NER、抽取式问答与语义角色标注。

## 论文简介

输入层软提示在十亿参数以下模型或较难的序列标注任务上，常与全量微调存在明显差距。P-Tuning v2 将已有深层提示思想系统适配到 NLU：冻结主干，在各层加入连续任务前缀，使用分类或逐 token 输出头，并研究长度、重参数化和多任务初始化的取舍。论文在约 300M 到 10B 的模型和多类理解任务上，以约 0.1%–3% 提示参数获得接近全量微调的效果，尤其缓解了输入层提示在抽取式问答上的困难。但并非每个数据集都追平基线，较小模型仍有差距；实验证据主要来自全监督双向理解模型，不能把标题中的“普遍”推广为所有聊天或生成任务的保证。

## 问题：输入层提示的两种不普遍性

第一种是规模：Lester 等人的研究显示输入提示在很大 T5 上有效，但常见的较小模型不一定能仅靠这段向量完成任务。第二种是任务结构：分类只输出一个标签，NER、抽取式 QA 和语义角色标注则需要对多个 token 或位置作预测，单个标签词填空接口不自然。

本文没有首次提出逐层提示。作者明确将贡献定位为深层提示在 NLU 上的优化、适配与系统实证，这一点有助于区分 Prefix-Tuning、P-Tuning v1 和 v2 的关系。

## 深层提示与输出头

对每层注意力提供独立的前缀条件，真实 token 可以在不同层直接读取任务信息。相较仅训练输入 embedding，更多层的直接条件增加了任务容量，并缩短提示影响深层预测的路径。以 K/V 视角，可理解为每层分别使用

$$
\operatorname{Attention}(Q_\ell,[K_{P,\ell};K_\ell],[V_{P,\ell};V_\ell]).
$$

具体参数量取决于层数、前缀长度和键值维度。论文将主干冻结，同时训练前缀及任务所需输出头；“冻结模型”不意味着额外分类头也不能学习。

![P-Tuning v2 原论文图 2：输入提示与逐层提示及任务头](figs/S2-F2-01.png)

左边通过输入提示和标签词输出，右边在各层加入任务前缀，并在真实 token 上使用适合任务的线性头。抽取式 QA 可以预测起止位置，NER 则逐位置输出类别，不再强制转成同一标签词填空形式。

## 实现细节不是统一开关

重参数化 MLP 对某些任务有帮助，对另外一些任务收益很小甚至下降，因此不是必选步骤。提示长度也与任务相关：较简单分类通常更短，较难序列标注往往需要更长提示。多任务预训练共享提示可以改善初始化，但也是额外的数据与训练流程，应与单任务 v2 区分。

正式 ACL 标题是 “P-Tuning: Prompt Tuning Can Be Comparable to Fine-tuning Across Scales and Tasks”，不带 v2；它对应的是预印本 2110.07602，不是 v1 的 “GPT Understands, Too”。实现中 PEFT 的 `P_TUNING` 通常表示输入层提示编码器，也不能仅凭名称将它当成本文完整深层方案。

## 数据和比较协议

论文使用 SuperGLUE 检验一般理解，并以 CoNLL03、OntoNotes、CoNLL04 等 NER 数据，以及 SQuAD 1.1/2.0 和语义角色标注评测更复杂的 token 任务。模型涵盖约 335M、355M、750M、2B、10B 等规模，主要是双向 NLU 架构。

比较中 FT 为全量微调，PT 表示论文中的输入层提示基线，PT-2 为 v2，MPT-2 为加入多任务训练的 v2。提示方法冻结主干，实验采用全监督设置；这些条件与 v1 部分联合微调结果不相同。

## 跨规模结果

摘自原文表 2，单元格依次为 FT / PT / PT-2：

| 模型 | BoolQ | RTE |
|---|---|---|
| BERT Large，335M | 77.7 / 67.2 / 75.8 | 70.4 / 53.5 / 78.3 |
| RoBERTa Large，355M | 86.9 / 62.3 / 84.8 | 86.6 / 58.8 / 89.5 |
| GLM XL，2B | 88.3 / 79.7 / 87.0 | 90.3 / 85.6 / 90.3 |
| GLM XXL，10B | 88.7 / 88.8 / 88.8 | 93.1 / 89.9 / 93.1 |

v2 在较小模型中大幅缩小差距，RTE 甚至超过 FT；大模型中的输入层提示自身也更有竞争力。但 BoolQ 的较小模型仍低于 FT，不能把“可比”解释成所有指标完全相等。

## 序列任务与消融

原论文表 3 中，RoBERTa Large 在 CoNLL03 的 FT / PT / PT-2 F1 为 92.6 / 86.1 / 92.8，在 SQuAD 1.1 开发集的 F1 为 94.6 / 12.0 / 94.4。深层提示显著缓解了抽取式任务的优化困难。

另一方面，BERT Large 的 SQuAD 1.1 F1 仍为 FT 91.1、PT-2 86.0，SQuAD 2.0 也有差距。后者包含不可回答问题，只有单层提示的异常结果反映其特定优化困难，不能直接说明模型完全没有问答知识。

作者还比较线性头与 verbalizer、不同提示深度、长度与 MLP。按层数控制参数预算时，靠近输出的层往往更有效；任务最优长度和重参数化收益不完全一致。多任务初始化可以改善部分序列任务，却没有在所有问答结果上统一获益。

## 结论与适用范围

本文说明深层提示能成为常见理解模型的一种有竞争力的适配方式，任务输出头和直接逐层条件都很重要。它的主要证据来自全监督 NLU，并不保证任意解码器生成、少样本或长上下文任务都能用相同配方替代全量微调。额外前缀的注意力、缓存和实现支持也应与任务参数比例分别计算。
