# Prompt Tuning：输入层软提示的规模效应

> **简述**：冻结语言模型，只学习输入序列前的一小段连续向量，并研究模型规模扩大后能否逼近全量微调。<br>
> **paper**：[The Power of Scale for Parameter-Efficient Prompt Tuning](https://arxiv.org/abs/2104.08691) · EMNLP 2021<br>
> **code**：[google-research/prompt-tuning](https://github.com/google-research/prompt-tuning) · **refs**：[Prefix-Tuning](https://arxiv.org/abs/2101.00190)<br>
> **backbone**：T5.1.1 Small–XXL（最高 11B） · **date**：2021-04<br>
> **modality / languages**：文本；核心评测为英语 SuperGLUE 与领域迁移。

## 论文简介

手写提示能够让冻结模型完成任务，却难以稳定利用大量标注数据；全量微调质量较强，但每个任务都要维护一套大权重。Prompt Tuning 用可学习的连续向量替代离散提示，只在输入 embedding 前拼接一段任务级软提示，冻结模型其余部分。论文通过 T5 的规模、提示长度、初始化和预训练目标消融发现，输入层提示在较小模型上存在明显差距，而在 11B 规模可接近强全量微调基线；部分领域迁移也更稳健。这个结果依赖 T5 及其 LM adaptation 等条件，不是所有大模型的普遍保证。方法虽极省任务参数，训练仍需穿过主干反向传播，推理也保留额外输入位置，软提示通常不能还原成一条自然语言指令。

## 核心问题：学习提示，而非搜索词表

离散提示从既有词表中选择 token，模型 embedding 被固定。Prompt Tuning 解除这个限制：让提示拥有自己的参数，利用梯度学习最适合任务的连续向量。它属于有监督训练，不是只把几条例子放进上下文的 in-context learning。

与 Prefix-Tuning 相比，本文只优化输入层的提示 embedding，不直接覆盖每层前缀激活。这减少了任务参数和实现复杂度，但任务信号需要通过冻结网络层层传播。论文的主要研究问题，是这种简单方案会如何随模型规模改变。

## 方法与训练目标

设输入 embedding 为 $E(x)\in\mathbb R^{n\times d}$，可学习提示为 $P\in\mathbb R^{m\times d}$，将二者拼接后送入 T5 编码器：

$$
\widetilde E=[P;E(x)],\qquad
\min_P -\sum_t\log p_{\theta_0}(y_t\mid \widetilde E,y_{<t}).
$$

基座 $\theta_0$ 冻结，只有 $P$ 更新。每个任务通常共享同一份提示，新增参数约为 $md$。任务统一为 text-to-text：例如分类时生成表示类别的文本，而不是额外训练一个巨大的任务模型。

提示不受真实词 embedding 的约束，因此可以学习到词表中不存在的向量。用最近邻词查看这些向量有时能保留初始化词的信息，却不能认为它们都可以解释为可读指令。

### 初始化与 LM adaptation

作者比较随机初始化、采样词表 embedding 和类别标签初始化。类别标签可以帮助模型建立输出空间，但在不同规模上收益不同；不能把某一初始化作为无需验证的必要条件。

T5.1.1 原先通过 span corruption 学习输出 sentinel 与被遮盖片段。冻结之后，仅靠提示未必容易克服这种输出习惯。因此作者继续用语言建模目标进行最多 100K 步 LM adaptation，得到之后可共享的基座。各任务只训练提示，不意味着准备基座本身完全没有额外训练成本。

## 实验设置和规模曲线

SuperGLUE 是八项英语理解任务，包括问答、因果选择、文本蕴含、词义和指代等。每个任务独立训练提示；单任务及多任务全量微调构成两类基线。默认提示长度 100，使用类别相关初始化、Adafactor、学习率 0.3、batch 32、30K 步，并在开发集选择 checkpoint。该学习率与特定优化器、参数化绑定，不能直接移作 LoRA 配方。

![Prompt Tuning 原论文图 1：规模与 SuperGLUE 表现](figs/S1-F1-01.png)

小 T5 的输入提示明显落后于模型微调，随着规模增大差距缩小，到 XXL（11B）时与强基线接近。图中的 GPT-3 离散提示曲线来自另一模型和训练设置，不能视为同一基座上仅切换适配器的控制实验。

## 消融：长度、初始化与目标都重要

长度消融测试 1、5、20、100、150 个提示位置。多数规模从一个位置增加到多个位置有明显帮助，超过一定长度后收益变小；大模型能用更短的提示完成任务。类别初始化在较小模型上通常更有帮助，到最大规模差异缩小。LM adaptation 的效果还随额外训练长度变化，说明预训练目标与下游控制接口之间存在适配成本。

这些消融共同解释了“规模效应”：更强的冻结模型更容易通过小条件调用相关行为，但大模型仍需要正确的训练数据、目标和输出格式。它不是“模型大了就不用训练提示”的结论。

## 领域迁移与泛化

原论文表 1 将在 SQuAD 上训练的模型零样本迁移到其他问答域，报告 F1 均值及标准差。部分代表值如下：

| 测试域 | 全量模型微调 | 提示微调 |
|---|---:|---:|
| SQuAD / Wiki | 94.9 ± 0.2 | 94.8 ± 0.1 |
| TextbookQA / 教材 | 54.3 ± 3.7 | 66.8 ± 2.9 |
| BioASQ / 生物医学 | 77.9 ± 0.4 | 79.1 ± 0.3 |
| DuoRC / 电影 | 68.9 ± 0.7 | 67.7 ± 1.1 |
| DROP / Wiki | 68.9 ± 1.7 | 67.1 ± 1.9 |

提示在教材域上明显更好，但也有测试集下降。冻结主干可能形成有益的约束，并不提供普遍的域外优势保证。Google Research 的作者博客还展示 QQP→MRPC 的准确率提高 3.2 个百分点，这是一个特定转移方向，不能扩展为所有任务固定收益。

## 共享服务与局限

任务参数很小，可让不同任务共享一个冻结模型，并在支持的实现中混合不同提示进行批处理。代价是额外输入位置、相关激活和注意力计算；训练并不因为只保存小提示就完全不需要主干反向传播。

本文最强证据来自 LM-adapted T5、英语任务和有限规模区间。输入层提示在较小模型或复杂序列标注中可能不足，后续 P-Tuning v2 对逐层提示和任务头的研究，正是在扩展这一能力边界。附录给出各任务分数、超参及提示分析，阅读曲线时也应保留其任务间差异。
